Who decides a payout

Only the agent reads untrusted text, and the agent cannot move money on its own.

The owner signs once

A passkey or wallet signature approves the payee set. Changing it later is a public on-chain event.

The agent can be fooled

We assume it will be. It can propose a payment, never execute one.

The contract has the last word

Our server holds no owner key. If the server is compromised, payouts still stay inside the signed set.

  • Cross-chain spending (ICM) is tested locally only.
